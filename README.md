A terse release note for a bug in human biology: contagious yawns, unpatched sneezes.

## The entry

**v9.3.2: fixed a bug where yawns were contagious across rooms; sneezes still bypass all permissions.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
